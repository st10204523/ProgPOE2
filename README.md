# Match It

## Overview
**Match It** is an engaging and challenging Android puzzle game where players match similar items within a time limit. Designed for players of all ages, the game offers both single and multiplayer modes, as well as global leaderboards to track progress.

## Features
- **Single & Multiplayer Modes**: Play solo or challenge friends online.
- **Leaderboard**: Track and compare the highest points in each game mode globally.
- **Login & Sign-up Options**: Log in with email/password or via Facebook.
- **Language Support**: Available in English and Afrikaans.
- **Customizable Settings**: Change language preferences, enable dark mode, and more.
- **Help Screen**: Get detailed instructions on how to play the game.

## Planned Features
The following features are planned for future implementation:
- **Language Selection**: Allow users to select their preferred language from the settings.
- **Notifications**: Provide users with updates and reminders related to the game.
- **Biometric Authentication**: Enable users to log in using fingerprint or facial recognition.
- **Ads**: Integrate advertisements to support the game.

## Usage
### Logging In
When you open Match It, you’ll be prompted to log in. You can log in using either your email and password or via Facebook.

### Email and Password
Enter your registered email and password to log in.
If you don’t have an account, tap Sign Up to create one.
Follow the prompts to register and log in.

### Facebook Login
Tap the Log in with Facebook button to use your Facebook account.
Once authenticated, you’ll be logged in and redirected to the main menu.

### Main Menu
After logging in, you will be directed to the main menu where you can access the following options:

Single Player: Play a solo game and aim for the best time.
Multiplayer: Challenge friends or other players online.
Leaderboard: View the highest points in each game mode.
Game Share & Creation: Create your own games or download games created by other users.
Settings: Change language preferences, toggle dark mode, and adjust other game settings.
Help: View instructions on how to play the game.

### Game Controls
Tap to Match: Select items by tapping them to make matches.
Timer: Complete matches before time runs out to advance.

### Game Over Screen
At the end of each game, a game over screen is displayed where users can:
View their scores.
Choose to go back to the main menu.
Opt to play again.

### Help Screen
For detailed instructions on how to play the game, visit the Help section in the app.

### Language Preference
The game supports two languages: English and Afrikaans. You can change your language preference in the Settings menu. (Feature coming soon)

### Leaderboard
The leaderboard displays the highest points achieved by players in each of the game modes, allowing for global competition and tracking.

### Game Share & Creation
Create Games: Players can create their own customized game levels.
Download Games: Access and play games created by other users to expand your gameplay experience.

### Settings
In the Settings menu, you can:
Change the language preference.
Enable or disable dark mode.
Turn on/off notifications. (Feature coming soon)
Enable/disable biometric authorization. (Feature coming soon)
